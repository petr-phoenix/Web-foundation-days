About QuickNotes

QuickNotes is a lightweight note-taking web page built to help you capture ideas instantly.

Created as part of the Web Foundations course, it demonstrates key semantic HTML standards, proper page structure, and accessible form design.

How to use quicknotes

  1. Type your note into the text input field on the main page.
  2. Click the "Add Note" button or press Enter to submit it.
  3. View your saved entries and keep track of your active note count.

Features

  • Add new notes quickly.
  • Track your existing notes.
  • Responsive design for mobile and desktop.

Keyboard Shortcuts

Shortcut Action
Enter Submit and add a new note.
